第一章 OLS 基础：一元线性回归
1.1 模型设定与经济意义
一元线性回归模型
$$y_i = \beta_1 + \beta_2 x_i + \varepsilon_i, \quad i = 1, 2, \ldots, n$$

其中 $y_i$ 为被解释变量（因变量），$x_i$ 为解释变量（自变量），$\varepsilon_i$ 为随机扰动项（误差项），包含一切未被 $x_i$ 捕捉的影响因素。

$\beta_2$ 是斜率：$x$ 每增加 1 个单位，$y$ 的条件期望变化 $\beta_2$ 个单位（偏效应）。

$\beta_1$ 是截距：$x=0$ 时 $y$ 的条件期望（通常无直接经济意义）。

回归 vs. 相关
  • 相关：度量两变量线性关系强弱，对称，$\text{Cor}(x,y) = \text{Cor}(y,x)$
  • 回归：用 $x$ 预测/解释 $y$，不对称，有方向，可用于因果推断（在额外假定下）
1.2 OLS 推导
最小二乘原则

OLS 选取 $(\hat{\beta}_1, \hat{\beta}_2)$ 最小化残差平方和：

$$\min_{\beta_1, \beta_2}\; Q(\beta_1, \beta_2) = \sum_{i=1}^{n}(y_i - \beta_1 - \beta_2 x_i)^2$$

对 $\beta_1, \beta_2$ 分别求偏导并令其为零（正规方程组）：

$$\frac{\partial Q}{\partial \beta_1} = -2\sum(y_i - \hat{\beta}_1 - \hat{\beta}_2 x_i) = 0 \implies \sum \hat{\varepsilon}_i = 0$$
$$\frac{\partial Q}{\partial \beta_2} = -2\sum x_i(y_i - \hat{\beta}_1 - \hat{\beta}_2 x_i) = 0 \implies \sum x_i \hat{\varepsilon}_i = 0$$
OLS 估计量的解析解
$$\hat{\beta}_2 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2} = \frac{S_{xy}}{S_{xx}}$$
$$\hat{\beta}_1 = \bar{y} - \hat{\beta}_2 \bar{x}$$

其中 $S_{xx} = \sum(x_i-\bar{x})^2$，$S_{xy} = \sum(x_i-\bar{x})(y_i-\bar{y})$。

注意：$\hat{\beta}_2 = r_{xy} \cdot \dfrac{s_y}{s_x}$（相关系数乘以标准差之比）。

OLS 残差的两个关键性质

由正规方程直接推出，无需任何假定：

  1. $\sum_{i=1}^{n} \hat{\varepsilon}_i = 0$（残差之和为零）
  2. $\sum_{i=1}^{n} x_i \hat{\varepsilon}_i = 0$（残差与 $x$ 正交）

推论：$\sum \hat{y}_i \hat{\varepsilon}_i = 0$，回归线必过 $(\bar{x}, \bar{y})$。

1.3 平方和分解与 $R^2$
定理：$SS_T = SS_R + SS_E$
$$\underbrace{\sum(y_i - \bar{y})^2}_{SS_T} = \underbrace{\sum(\hat{y}_i - \bar{y})^2}_{SS_R \text{（回归）}} + \underbrace{\sum \hat{\varepsilon}_i^2}_{SS_E \text{（残差）}}$$
$$R^2 = \frac{SS_R}{SS_T} = 1 - \frac{SS_E}{SS_T} \in [0, 1]$$

$R^2$ 表示回归模型能解释的 $y$ 的变异比例。一元回归中 $R^2 = r_{xy}^2$。

$R^2$ 的局限性
  • 加入任意变量（哪怕不相关）都不会使 $R^2$ 下降，导致模型过度扩张。
  • 调整 $R^2$（Adjusted $R^2$）惩罚参数个数：$\bar{R}^2 = 1 - \dfrac{SS_E/(n-k)}{SS_T/(n-1)}$，其中 $k$ 为参数个数（含截距）。
  • $R^2$ 高不代表因果关系，$R^2$ 低不代表模型没用。
第二章 多元线性回归：矩阵推导
2.1 矩阵表示
多元回归的矩阵形式

设有 $n$ 个观测、$K$ 个参数（含截距），令：

$$\bm{y} = \bm{X\beta} + \bm{\varepsilon}$$

其中：

$$\bm{y} = \begin{pmatrix}y_1\\\vdots\\y_n\end{pmatrix}_{n\times 1}, \quad \bm{X} = \begin{pmatrix}1 & x_{12} & \cdots & x_{1K}\\1 & x_{22} & \cdots & x_{2K}\\\vdots & \vdots & & \vdots\\1 & x_{n2} & \cdots & x_{nK}\end{pmatrix}_{n\times K}, \quad \bm{\beta} = \begin{pmatrix}\beta_1\\\vdots\\\beta_K\end{pmatrix}_{K\times 1}, \quad \bm{\varepsilon} = \begin{pmatrix}\varepsilon_1\\\vdots\\\varepsilon_n\end{pmatrix}_{n\times 1}$$
2.2 OLS 矩阵推导
定理：OLS 估计量的矩阵解

最小化 $\bm{\varepsilon}'\bm{\varepsilon} = (\bm{y} - \bm{X\beta})'(\bm{y} - \bm{X\beta})$，展开：

$$Q = \bm{y}'\bm{y} - 2\bm{\beta}'\bm{X}'\bm{y} + \bm{\beta}'\bm{X}'\bm{X\beta}$$

对 $\bm{\beta}$ 求导并令其为零（正规方程）：

$$\frac{\partial Q}{\partial \bm{\beta}} = -2\bm{X}'\bm{y} + 2\bm{X}'\bm{X}\hat{\bm{\beta}} = \bm{0}$$

当 $\bm{X}'\bm{X}$ 可逆（即不存在完全多重共线性）时：

$$\boxed{\hat{\bm{\beta}} = (\bm{X}'\bm{X})^{-1}\bm{X}'\bm{y}}$$
$\hat{\bm{\beta}}$ 的展开分析

将 $\bm{y} = \bm{X\beta} + \bm{\varepsilon}$ 代入：

$$\hat{\bm{\beta}} = (\bm{X}'\bm{X})^{-1}\bm{X}'(\bm{X\beta} + \bm{\varepsilon}) = \bm{\beta} + (\bm{X}'\bm{X})^{-1}\bm{X}'\bm{\varepsilon}$$

这个展开式是分析 OLS 偏误和方差的核心出发点。当 $E(\bm{\varepsilon}|\bm{X}) = \bm{0}$ 时，$E(\hat{\bm{\beta}}|\bm{X}) = \bm{\beta}$，即 OLS 无偏。

2.3 投影矩阵
定义：帽子矩阵（投影矩阵）
$$\bm{H} = \bm{X}(\bm{X}'\bm{X})^{-1}\bm{X}', \quad \bm{M} = \bm{I} - \bm{H}$$

则拟合值 $\hat{\bm{y}} = \bm{H}\bm{y}$，残差 $\hat{\bm{\varepsilon}} = \bm{M}\bm{y} = \bm{M\varepsilon}$。

$\bm{H}$ 的性质：幂等（$\bm{H}^2 = \bm{H}$），对称，秩为 $K$；$\bm{M}$ 同样幂等对称，秩为 $n-K$。

几何意义：$\bm{H}$ 是向 $\bm{X}$ 列空间的投影算子；$\bm{M}$ 是向 $\bm{X}$ 列空间正交补的投影算子。

第三章 Gauss-Markov 定理与 OLS 性质
3.1 经典假定（CLM Assumptions）
CLM 假定（Classical Linear Model）
编号假定名称数学表述
A1线性性$\bm{y} = \bm{X\beta} + \bm{\varepsilon}$，参数线性
A2严格外生性$E(\bm{\varepsilon}|\bm{X}) = \bm{0}$
A3无完全共线$\text{rank}(\bm{X}) = K$，$(\bm{X}'\bm{X})$ 可逆
A4球形扰动项$\text{Var}(\bm{\varepsilon}|\bm{X}) = \sigma^2 \bm{I}$（同方差 + 无自相关）
A5正态性$\bm{\varepsilon}|\bm{X} \sim N(\bm{0}, \sigma^2\bm{I})$

A1–A4 是 Gauss-Markov 定理的假定；A5 附加后支持有限样本下的精确推断（$t, F$ 检验）。

关于 A2：严格外生性的含义

$E(\varepsilon_i | x_1, \ldots, x_n) = 0$ 要求：扰动项与所有观测值无关，包括其他时期的 $x$。这比 $E(\varepsilon_i | x_i) = 0$（弱外生性）更强。

实践中更常用的版本：$E(\varepsilon_i | x_i) = 0$，即 $\text{Cov}(x_i, \varepsilon_i) = 0$。

违反外生性（$\text{Cov}(x_i, \varepsilon_i) \neq 0$）是内生性问题，导致 OLS 有偏且不一致。

3.2 OLS 的无偏性与方差
定理：OLS 的无偏性（在 A1–A3 下）
$$E(\hat{\bm{\beta}} | \bm{X}) = \bm{\beta}$$

证明：由 $\hat{\bm{\beta}} = \bm{\beta} + (\bm{X}'\bm{X})^{-1}\bm{X}'\bm{\varepsilon}$，取期望：

$$E(\hat{\bm{\beta}}|\bm{X}) = \bm{\beta} + (\bm{X}'\bm{X})^{-1}\bm{X}'\underbrace{E(\bm{\varepsilon}|\bm{X})}_{=\bm{0}} = \bm{\beta} \quad \square$$
定理：OLS 估计量的方差（在 A1–A4 下）
$$\text{Var}(\hat{\bm{\beta}}|\bm{X}) = \sigma^2(\bm{X}'\bm{X})^{-1}$$

证明：$\hat{\bm{\beta}} - \bm{\beta} = (\bm{X}'\bm{X})^{-1}\bm{X}'\bm{\varepsilon}$，令 $\bm{A} = (\bm{X}'\bm{X})^{-1}\bm{X}'$：

$$\text{Var}(\hat{\bm{\beta}}|\bm{X}) = \bm{A}\,\text{Var}(\bm{\varepsilon}|\bm{X})\,\bm{A}' = \bm{A}\cdot\sigma^2\bm{I}\cdot\bm{A}' = \sigma^2\bm{A}\bm{A}' = \sigma^2(\bm{X}'\bm{X})^{-1} \quad \square$$

$\sigma^2$ 的无偏估计量：$\hat{\sigma}^2 = \dfrac{\hat{\bm{\varepsilon}}'\hat{\bm{\varepsilon}}}{n-K} = \dfrac{SS_E}{n-K}$（分母为自由度 $n-K$）。

3.3 Gauss-Markov 定理
定理：Gauss-Markov（在 A1–A4 下）

在所有线性无偏估计量（BLUE）中，OLS 估计量具有最小方差：

$$\text{Var}(\tilde{\beta}_k) \geq \text{Var}(\hat{\beta}_k^{\text{OLS}}), \quad \forall k$$

对任何线性无偏估计量 $\tilde{\bm{\beta}} = \bm{Cy}$（$E(\tilde{\bm{\beta}}) = \bm{\beta}$）均成立。

BLUE = Best Linear Unbiased Estimator（最优线性无偏估计量）

证明思路

令 $\bm{D} = \bm{C} - (\bm{X}'\bm{X})^{-1}\bm{X}'$，由无偏性推出 $\bm{DX} = \bm{0}$。

则 $\text{Var}(\tilde{\bm{\beta}}|\bm{X}) = \sigma^2(\bm{D}\bm{D}' + (\bm{X}'\bm{X})^{-1})$。

因为 $\bm{DD}'$ 是半正定矩阵，故 $\text{Var}(\tilde{\bm{\beta}}) \geq \text{Var}(\hat{\bm{\beta}}^{\text{OLS}})$（矩阵半正定意义）。$\square$

Gauss-Markov 的边界

GM 定理只说 OLS 在线性无偏类中最优。如果：

  • 允许有偏（如岭回归）：可以牺牲无偏换取更小总 MSE
  • 非线性估计量：理论上可超越 OLS
  • A4 违反（异方差/自相关）：WLS/GLS 在线性无偏类中优于 OLS
第四章 假设检验与模型评价
4.1 单个系数的 $t$ 检验
$t$ 检验（在 A1–A5 下）

$H_0: \beta_k = \beta_k^0$，检验统计量：

$$t = \frac{\hat{\beta}_k - \beta_k^0}{\hat{\text{se}}(\hat{\beta}_k)} \sim t(n-K)$$

其中标准误 $\hat{\text{se}}(\hat{\beta}_k) = \hat{\sigma}\sqrt{[(\bm{X}'\bm{X})^{-1}]_{kk}}$。

最常用：$H_0: \beta_k = 0$（解释变量 $k$ 对 $y$ 无影响），$t = \hat{\beta}_k / \hat{\text{se}}(\hat{\beta}_k)$。

置信区间与 $t$ 检验的对偶性

$\beta_k$ 的 $(1-\alpha)$ 置信区间：$\hat{\beta}_k \pm t_{\alpha/2}(n-K)\cdot\hat{\text{se}}(\hat{\beta}_k)$

若置信区间不含 0，则在水平 $\alpha$ 下拒绝 $H_0: \beta_k = 0$。两者完全等价。

4.2 联合显著性：$F$ 检验
$F$ 检验（整体显著性）

$H_0: \beta_2 = \beta_3 = \cdots = \beta_K = 0$（所有斜率系数均为零）：

$$F = \frac{SS_R / (K-1)}{SS_E / (n-K)} = \frac{R^2/(K-1)}{(1-R^2)/(n-K)} \sim F(K-1, n-K)$$

若 $F > F_\alpha(K-1, n-K)$，拒绝 $H_0$，认为模型整体显著。

线性约束的 $F$ 检验（一般形式）

检验 $J$ 个线性约束 $H_0: \bm{R\beta} = \bm{r}$，比较受约束模型（R）与无约束模型（U）：

$$F = \frac{(SS_E^R - SS_E^U)/J}{SS_E^U/(n-K)} = \frac{(R_U^2 - R_R^2)/J}{(1-R_U^2)/(n-K)} \sim F(J, n-K)$$

约束越"贵"（加约束后 $SS_E$ 增加越多），$F$ 越大，越倾向拒绝 $H_0$。

4.3 信息准则
AIC 与 BIC
$$\text{AIC} = -2\ln L + 2K, \qquad \text{BIC} = -2\ln L + K\ln n$$

值越小越好。BIC 对参数个数的惩罚更重（当 $n > 7$ 时 $\ln n > 2$），倾向选择更简约的模型。用于非嵌套模型比较。

第五章 虚拟变量与交互项
5.1 虚拟变量
虚拟变量的设置

对具有 $m$ 个类别的定性变量，只引入 $m-1$ 个虚拟变量（避免虚拟变量陷阱：完全共线性）。

模型：$y_i = \beta_1 + \beta_2 D_i + \beta_3 x_i + \varepsilon_i$，其中 $D_i \in \{0,1\}$。

$\beta_2$ 的含义：在 $x_i$ 相同条件下，$D=1$ 组相对于基准组（$D=0$）的均值差异。

虚拟变量陷阱

若模型含截距，且引入所有 $m$ 个虚拟变量，则 $D_1 + D_2 + \cdots + D_m = \bm{1}$（截距列），$\bm{X}$ 不满秩，$(\bm{X}'\bm{X})$ 不可逆。

解决：删去一个类别作为基准组（参照组），其余系数解释为相对于基准组的差异。

5.2 交互项与异质效应
交互项的设置与解释

模型：$y_i = \beta_1 + \beta_2 x_i + \beta_3 D_i + \beta_4 (x_i \cdot D_i) + \varepsilon_i$

偏效应：$\dfrac{\partial E(y|x, D)}{\partial x} = \beta_2 + \beta_4 D_i$

  • $D=0$ 时，$x$ 的效应为 $\beta_2$
  • $D=1$ 时，$x$ 的效应为 $\beta_2 + \beta_4$
  • $\beta_4$：两组之间效应的差异（效应异质性）
对数形式的解释
模型形式$\beta_2$ 的含义
$y = \beta_1 + \beta_2 x$（线性-线性）$x$ 增加 1，$y$ 增加 $\beta_2$（绝对效应）
$\ln y = \beta_1 + \beta_2 x$（对数-线性）$x$ 增加 1，$y$ 增加约 $100\beta_2\%$
$y = \beta_1 + \beta_2 \ln x$（线性-对数）$x$ 增加 $1\%$，$y$ 增加 $\beta_2/100$
$\ln y = \beta_1 + \beta_2 \ln x$（双对数）$x$ 增加 $1\%$，$y$ 增加约 $\beta_2\%$（弹性）
第六章 多重共线性
6.1 什么是多重共线性
定义

完全共线性：$\bm{X}$ 的某列是其他列的精确线性组合，$\text{rank}(\bm{X}) < K$，$(\bm{X}'\bm{X})$ 奇异，OLS 无解。

近似共线性（更常见）：解释变量之间高度相关，但 $(\bm{X}'\bm{X})$ 仍可逆。OLS 可以估计，但结果不稳定。

6.2 后果与诊断
多重共线性的后果

OLS 仍然无偏（GM 定理不受影响），但：

  • $\text{Var}(\hat{\beta}_k) = \sigma^2 \cdot \dfrac{1}{S_{kk}(1-R_k^2)}$ 膨胀，$t$ 统计量偏小
  • 系数估计量对数据变化极度敏感，加减一个样本或变量可能使结果大幅改变
  • 系数符号可能"错误"（与理论相反）

其中 $R_k^2$ 是第 $k$ 个解释变量对其他解释变量回归的 $R^2$。

诊断指标：方差膨胀因子（VIF）
$$\text{VIF}_k = \frac{1}{1 - R_k^2}$$

经验判断：$\text{VIF}_k > 10$ 通常认为存在严重多重共线性（部分文献用 $>5$）。

Stata 命令：回归后输入 vif。

处理方法
  1. 增加样本量（降低方差）
  2. 删去高度相关的变量（但可能引入遗漏变量偏误，需权衡）
  3. 利用先验信息约束系数（岭回归）
  4. 改用主成分回归（PCA）
  5. 若目的是预测而非推断，多重共线性影响较小
第七章 异方差
7.1 异方差的定义与后果
定义：异方差

违反 A4 的同方差假定：$\text{Var}(\varepsilon_i | x_i) = \sigma_i^2$，各观测的扰动项方差不同。

异方差的后果
  • OLS 仍然无偏：A2 未违反，$E(\hat{\bm{\beta}}) = \bm{\beta}$ 仍成立
  • OLS 不再是 BLUE：A4 违反，GM 定理不适用，WLS 更有效
  • OLS 标准误误导性：若使用普通标准误，$t$ 和 $F$ 统计量失效，推断不可靠
7.2 检验异方差
White 检验

辅助回归：将 $\hat{\varepsilon}_i^2$ 对 $x_i$、$x_i^2$ 及 $x_i x_j$ 回归，$H_0$：无异方差。

$$LM = nR^2 \xrightarrow{d} \chi^2(q) \quad \text{（} H_0 \text{ 成立时）}$$

其中 $q$ 为辅助回归中解释变量个数（不含截距）。Stata：estat imtest, white

Breusch-Pagan (BP) 检验

辅助回归：将 $\hat{\varepsilon}_i^2 / \hat{\sigma}^2$ 对 $x_i$ 回归（假设方差是 $x_i$ 的线性函数）：

$$LM = \frac{SS_R^*}{2} \xrightarrow{d} \chi^2(K-1)$$

Stata：estat hettest（BP 检验），estat imtest, white（White 检验）

7.3 修正异方差
方法一：White 稳健标准误

不改变 OLS 点估计，仅修正协方差矩阵估计：

$$\widehat{\text{Var}}(\hat{\bm{\beta}})_{\text{robust}} = (\bm{X}'\bm{X})^{-1}\left(\sum_{i=1}^{n}\hat{\varepsilon}_i^2 \bm{x}_i\bm{x}_i'\right)(\bm{X}'\bm{X})^{-1}$$

Stata：在 regress 后加 , robust 选项。robust

优点：无需知道异方差的具体形式，渐近有效。缺点：小样本表现有时不佳。

方法二：加权最小二乘（WLS）

若 $\text{Var}(\varepsilon_i) = \sigma^2 / w_i$（权重 $w_i$ 已知或可估计），以 $\sqrt{w_i}$ 为权重变换模型：

$$\sqrt{w_i}\,y_i = \sqrt{w_i}\,\beta_1 + \sum_k \sqrt{w_i}\,\beta_k x_{ki} + \sqrt{w_i}\,\varepsilon_i$$

变换后的扰动项 $\sqrt{w_i}\,\varepsilon_i$ 满足同方差，对变换后的模型做 OLS 即为 WLS。

Stata：regress y x1 x2 [aweight = w]

第八章 自相关
8.1 自相关的定义与来源
定义：自相关

违反 A4 中的"无自相关"部分：$\text{Cov}(\varepsilon_i, \varepsilon_j) \neq 0$，$i \neq j$。主要出现在时间序列数据中。

AR(1) 扰动项（一阶自回归过程）：

$$\varepsilon_t = \rho\,\varepsilon_{t-1} + u_t, \quad u_t \overset{\text{iid}}{\sim}(0, \sigma_u^2), \quad |\rho| < 1$$

则 $\text{Var}(\varepsilon_t) = \dfrac{\sigma_u^2}{1-\rho^2}$，$\text{Cov}(\varepsilon_t, \varepsilon_{t-s}) = \dfrac{\rho^s\sigma_u^2}{1-\rho^2}$。

自相关的后果

与异方差类似：OLS 无偏，但不是 BLUE，且普通标准误失效。

正自相关（$\rho > 0$）时，OLS 标准误被低估（实际 $t$ 统计量偏大），过度拒绝 $H_0$，结论过于"显著"。

8.2 检验自相关
Durbin-Watson (DW) 检验

$H_0: \rho = 0$，统计量：

$$DW = \frac{\sum_{t=2}^{n}(\hat{\varepsilon}_t - \hat{\varepsilon}_{t-1})^2}{\sum_{t=1}^{n}\hat{\varepsilon}_t^2} \approx 2(1 - \hat{\rho})$$

$DW \approx 2$：无自相关；$DW \approx 0$：强正自相关；$DW \approx 4$：强负自相关。

利用 $d_L, d_U$ 临界值判断（存在不确定区间）。

限制：模型必须含截距；不适用于滞后因变量作为解释变量的模型。

Breusch-Godfrey (BG) 检验

将残差 $\hat{\varepsilon}_t$ 对原模型解释变量及 $\hat{\varepsilon}_{t-1}, \ldots, \hat{\varepsilon}_{t-p}$ 回归：

$$LM = nR^2 \xrightarrow{d} \chi^2(p)$$

可检验高阶自相关，适用于滞后因变量模型。Stata：estat bgodfrey, lags(p)

8.3 修正自相关
方法一：Newey-West HAC 标准误

异方差-自相关稳健（HAC）标准误，修正协方差矩阵：

$$\widehat{\text{Var}}(\hat{\bm{\beta}})_{\text{HAC}} = (\bm{X}'\bm{X})^{-1}\hat{\bm{S}}(\bm{X}'\bm{X})^{-1}$$

Stata：regress y x, newey-west 或 newey y x, lag(p)

方法二：GLS（广义最小二乘）

若 $\varepsilon_t = \rho\varepsilon_{t-1} + u_t$，用 Prais-Winsten 或 Cochrane-Orcutt 变换消除自相关。

变换后模型：$(y_t - \rho y_{t-1}) = \beta_1(1-\rho) + \beta_2(x_t - \rho x_{t-1}) + u_t$，对 $u_t$ 做 OLS。

第九章 内生性与工具变量
9.1 内生性的来源
内生性：$\text{Cov}(x_i, \varepsilon_i) \neq 0$

三大来源：

  1. 遗漏变量偏误：遗漏了与 $x$ 和 $y$ 均相关的变量 $z$。
    例：研究教育对工资的影响，遗漏"能力"变量。能力影响教育年限（$\text{Cov}(x, z) \neq 0$）且直接影响工资（$z$ 在 $\varepsilon$ 中）。
  2. 测量误差：解释变量 $x_i^* = x_i + v_i$（含测量误差 $v_i$），实际回归中 $\varepsilon_i$ 包含 $-\beta_2 v_i$，与 $x_i^*$ 相关。导致衰减偏误（attenuation bias）：$|\hat{\beta}_2| < |\beta_2|$。
  3. 联立性偏误：$y$ 和 $x$ 互为因果（如供求模型中价格和数量同时决定）。
遗漏变量偏误的量化

真实模型：$y = \beta_1 + \beta_2 x + \beta_3 z + u$，但实际回归遗漏 $z$：

$$\text{plim}(\hat{\beta}_2^{\text{OLS}}) = \beta_2 + \beta_3 \cdot \frac{\text{Cov}(x, z)}{\text{Var}(x)}$$

偏误方向由 $\beta_3 \cdot \text{Cov}(x,z)$ 的符号决定：

$\text{Cov}(x,z)$$\beta_3 > 0$$\beta_3 < 0$
正向上偏（高估 $\beta_2$）向下偏（低估 $|\beta_2|$）
负向下偏向上偏
9.2 工具变量估计（IV/2SLS）
有效工具变量的两个条件

对于内生变量 $x_i$，工具变量 $z_i$ 必须满足：

  1. 相关性（Relevance）：$\text{Cov}(z_i, x_i) \neq 0$，工具变量与内生变量相关
  2. 外生性（Exogeneity）：$\text{Cov}(z_i, \varepsilon_i) = 0$，工具变量与扰动项不相关（只通过 $x$ 影响 $y$）

注意：外生性条件无法由数据直接检验（$\varepsilon_i$ 不可观测），需要理论/经济直觉支撑。

IV 估计量

恰好识别（一个内生变量，一个工具变量）：

$$\hat{\beta}_2^{\text{IV}} = \frac{\text{Cov}(z_i, y_i)}{\text{Cov}(z_i, x_i)} = \frac{\sum(z_i - \bar{z})(y_i - \bar{y})}{\sum(z_i - \bar{z})(x_i - \bar{x})}$$

矩阵形式：$\hat{\bm{\beta}}^{\text{IV}} = (\bm{Z}'\bm{X})^{-1}\bm{Z}'\bm{y}$，其中 $\bm{Z}$ 为工具变量矩阵。

$$\text{plim}(\hat{\beta}_2^{\text{IV}}) = \beta_2 + \frac{\text{Cov}(z, \varepsilon)}{\text{Cov}(z, x)} = \beta_2 \quad \text{（当 } z \text{ 外生时）}$$
两阶段最小二乘（2SLS）

过度识别（工具变量多于内生变量）时使用 2SLS：

第一阶段：将内生变量 $x$ 对所有工具变量 $\bm{Z}$ 回归，得拟合值 $\hat{x}$
第二阶段：将 $y$ 对 $\hat{x}$（及其他外生变量）回归，得 $\hat{\beta}^{\text{2SLS}}$

第一阶段 $F$ 统计量 $> 10$：工具变量相关性强（弱工具变量的判断标准，陈强推荐 $F > 10$）。

Stata：ivregress 2sls y x1 (x2 = z1 z2), first

过度识别检验（Sargan-Hansen J 检验）

过度识别时，可检验工具变量外生性的一致性（但不能全部证伪）：

$$J = n \cdot R^2_{\hat{\varepsilon}^{\text{IV}} \sim \bm{Z}} \xrightarrow{d} \chi^2(L - K)$$

$L$ 为工具变量个数，$K$ 为内生变量个数。$p$ 值大 → 不拒绝工具变量外生性。

Stata：estat overid（2SLS 后）

第十章 模型设定与稳健性
10.1 函数形式设定
Ramsey RESET 检验

检验是否存在函数形式错误（遗漏非线性项）：

原模型回归，得拟合值 $\hat{y}$
辅助回归：$y$ 对原解释变量加 $\hat{y}^2, \hat{y}^3$ 回归
$F$ 检验新加项的联合显著性，$H_0$：函数形式正确

Stata：ovtest（回归后）
